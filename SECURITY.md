# Security Policy

## Supported Versions

| Version | Supported |
|:--|:--|
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in Task Manager, please do not open a public GitHub issue.

Report vulnerabilities privately by email to `security@wavedepth.com` or via GitHub Private Vulnerability Reporting. Include:

1. A clear description of the issue.
2. Steps or a minimal reproduction script.
3. Affected versions and environments.

You will receive an acknowledgment within 48 hours, followed by updates on triage and mitigation.
