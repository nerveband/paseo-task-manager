# Security Policy

## Supported Versions

| Version | Supported |
|:--|:--|
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in Task Manager, please do not open a public GitHub issue.

Use the repository's Security tab to report a vulnerability privately when private reporting is enabled. If no private reporting channel is available, open an issue asking the maintainer for one without including exploit details, personal data, or credentials. A private report should include:

1. A clear description of the issue.
2. Steps or a minimal reproduction script.
3. Affected versions and environments.

This is a community-maintained project. No response-time guarantee is offered.
